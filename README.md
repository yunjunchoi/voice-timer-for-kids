# Voice Stopwatch Timer For Kids - PWA

> 🌍 **Multi-language support**: Korean, English, Chinese, Japanese, Spanish, Portuguese, French

## 📱 Features

- ⏱️ **Stopwatch** with voice counting (1-100 all numbers, 100+ every 5)
- ⏲️ **Timer** with voice countdown (100+ every 10 sec, 1-100 all numbers)
- 🔊 **Voice counting** in multiple languages
- 🔔 **Alarm sound** when timer ends
- 🌐 **Auto-detect language** from browser settings
- 📱 **PWA** - Install as app on home screen
- 🔌 **Offline** support
- 🌙 **Wake lock** - Screen stays on during countdown

## 🌍 Supported Languages

- 🇰🇷 **한국어** (Korean)
- 🇺🇸 **English**
- 🇨🇳 **中文** (Chinese Simplified)
- 🇯🇵 **日本語** (Japanese)
- 🇪🇸 **Español** (Spanish)
- 🇧🇷 **Português** (Portuguese - Brazil)
- 🇫🇷 **Français** (French)

Auto-detects browser language and sets UI + voice accordingly!

## ⚙️ Settings

- 🔊 Voice Count on/off
- 🔔 Alarm Sound on/off
- 🌐 Language selection
- 🎙️ Voice selection (male/female)
- ⚡ Speed control (0.5x ~ 3x)
- 🎵 Pitch control (0.5x ~ 2x)

## 📖 Usage

### Stopwatch
1. Select "Stopwatch" mode
2. Turn on voice counting
3. Press "Start"
4. Counts: 1, 2, 3... 98, 99, 100, 105, 110...

### Timer
1. Select "Timer" mode
2. Enter minutes and/or seconds (can enter 500 in seconds → auto converts to 8:20)
3. Turn on voice + alarm
4. Press "Start"
5. Countdown with voice
6. Alarm beeps when time is up!

## 🛠️ Tech Stack

- Pure HTML/CSS/JavaScript (no dependencies!)
- Web Speech API (voice synthesis)
- Web Audio API (alarm sound)
- Service Worker (offline support)
- Wake Lock API (screen on)
